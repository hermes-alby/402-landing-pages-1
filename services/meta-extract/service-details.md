## Service

### Description
Meta-Extract is a pay-per-call API that pulls every metadata field from any URL in one request — Open Graph tags, Twitter Cards, JSON-LD structured data, favicons, canonical URLs, RSS feeds, and robots directives. Built for AI agents and developers who need reliable, structured metadata without maintaining their own scrapers.

### USPs
- **Complete extraction in one call:** Open Graph, Twitter Cards, JSON-LD, favicon, canonical URL, RSS feeds, and robots directives — all returned in a single structured response.
- **Agent-native access:** Works via REST, MCP (Claude, Cursor, Windsurf), and x402 micropayments — built for autonomous AI workflows.
- **No signup, no subscription:** Pay only per request starting at €0.03. No API keys to manage, no monthly bills.
