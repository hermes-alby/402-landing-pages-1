## Service

### Description
Instagram Profiles Download API is a pay-per-call gateway for retrieving public Instagram profile metadata, recent posts, follower counts, and media references. It is designed for developers, marketing teams, and AI agents that need on-demand profile data without maintaining Instagram credentials or a subscription service.

### USPs
- **Pay-per-call public profile downloads:** No monthly plan, no credits, no subscription overhead.
- **Agent-native access:** Built for MCP/x402 agent discovery and payment flows.
- **Public profile metadata and post references:** One request returns profile fields, recent public posts, follower metrics, and media URLs.
- **No Instagram API key:** The gateway avoids Instagram account integration and uses pay-per-request access instead.
